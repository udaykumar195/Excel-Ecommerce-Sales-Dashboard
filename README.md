## About the Project

This project is an **E-Commerce Sales Analytics Dashboard** developed in Microsoft Excel.

It takes transaction-level sales data and converts it into an interactive dashboard for exploring **revenue, profit, orders, categories, regions, shipping modes, and monthly performance**.

The workbook contains **1,000 orders covering 2024–2025**.

---

## 📊 Key Metrics

| Metric | Value |
|---|---:|
| **Total Orders** | 1,000 |
| **Total Revenue** | $90,202.61 |
| **Total Profit** | $28,148.13 |
| **Profit Margin** | 31.21% |
| **Period** | 2024–2025 |

---

## 🔎 What the Dashboard Shows

- Revenue & Profit by **Category**
- Revenue & Profit by **Region**
- Revenue by **Ship Mode**
- Monthly Revenue comparison for **2024 vs 2025**
- KPI cards for core business metrics
- Interactive **Slicers** for:
  - Category
  - Region
  - Ship Mode
  - Year

The slicers allow the dashboard to be filtered interactively so users can explore different segments of the dataset.

---

## 🧹 Data Preparation & Analysis

The workbook includes:

- Raw transaction data
- Cleaned and structured data
- Calculated **Year** and **Month** fields
- Calculated **Profit Margin**
- PivotTable-based analysis
- Pivot Charts
- Interactive dashboard filters
- Consistent financial and date formatting

| Sheet | Purpose |

| **Pivot_Data** | PivotTable analysis used for reporting |
| **Dashboard** | Final interactive dashboard |

## 💡 Selected Insights

- **Electronics** generated the highest category revenue: **$27,669.23**.
- **North** generated the highest regional revenue: **$19,797.28**.
- **Standard** shipping generated the highest revenue: **$50,210.44**.
- Revenue totaled **$46,999.32 in 2024** and **$43,203.29 in 2025**.
- **December** recorded the highest combined monthly revenue across the two years: **$11,073.11**.
